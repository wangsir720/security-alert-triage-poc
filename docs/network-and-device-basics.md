# 网络与安全设备基础

## 网络基础

### TCP/IP

- IP 负责寻址和路由；
- TCP 提供面向连接的可靠传输；
- UDP 适用于对时延敏感但允许丢包的场景；
- 安全分析需要关注源/目的地址、端口、协议、连接方向和时间窗口。

### DNS

- 将域名解析为 IP；
- 恶意域名、DGA、DNS 隧道和 C2 常通过 DNS 暴露；
- 安全运营需要保留 DNS 请求日志并关联终端和用户。

### HTTP/HTTPS

- HTTP 是 Web 请求和响应的基础；
- HTTPS 使用 TLS 加密传输；
- WAF、代理和 NDR 需要根据部署位置决定可见性。

## 常见设备与部署位置

| 设备 | 主要位置 | 解决的问题 |
|---|---|---|
| 防火墙 | 网络边界和区域隔离 | 访问控制、网络分段 |
| IPS | 关键链路 | 检测和阻断已知攻击流量 |
| WAF | Web 业务入口 | SQL 注入、XSS、Webshell 等攻击检测 |
| EDR | 终端和服务器 | 进程、文件、账号和主机行为检测 |
| NDR | 核心网络流量 | 流量异常、横向移动和 C2 检测 |
| SIEM | 日志分析中心 | 多源日志汇聚、关联和告警 |

## 安全运营链路

```text
资产与日志源
  -> 采集与解析
  -> 检测与告警
  -> 情报富化
  -> 分诊与调查
  -> 处置与闭环
  -> 报告与优化
```

## 售前表达重点

售前不需要把每个设备讲到产品级深度，但必须能解释：

- 设备部署在哪里；
- 能看到什么数据；
- 解决什么安全风险；
- 与哪些系统联动；
- 客户为什么需要它。
