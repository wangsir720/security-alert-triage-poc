# 成本收益测算

## POC 成本

| 项目 | 估算 |
|---|---:|
| 本地开发和文档 | 3-5 人天 |
| 运行环境 | 1 台普通 Linux 主机或本地 Docker |
| 外部 API | MVP 阶段为 0 元，使用本地样例数据 |
| 后续情报 API | 根据调用量和供应商报价确定 |

## 可量化收益

生产环境完成对照测试后，建议记录：

- 单条告警平均初筛耗时；
- 人工查询 IOC 的次数；
- 系统自动富化覆盖率；
- 高中低风险处理准确率；
- 报告生成耗时；
- 分析师每日可处理告警数量。

## 价值表达

售前不应只讲“用了威胁情报”，而应该把系统能力映射为客户指标：

```text
告警初筛时间下降
+ 重复查询工作量下降
+ 高危事件优先级更清晰
+ 处置记录更完整
```

## 边界

当前项目没有真实客户基线，因此不将目标值冒充实测值。正式 POC 必须先完成基线和对照测试，再形成成本收益结论。
