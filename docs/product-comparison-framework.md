# 安全厂商能力对比框架

> 只使用官网、产品手册、公开招标文件和公开报告，不编造客户效果与真实成交数据。

## 对比维度

| 维度 | 说明 |
|---|---|
| 产品定位 | 威胁情报、NDR、EDR、Web 安全、综合安全平台 |
| 核心能力 | 检测、响应、情报、SaaS/MDR、管理平台 |
| 交付形态 | 软件、硬件、SaaS、私有化、托管服务 |
| 适用客户 | 政企、金融、运营商、教育、互联网 |
| 生态集成 | SIEM、SOAR、EDR、API、MCP/Agent |
| 运营价值 | 降噪、告警关联、响应效率、续订与服务化 |
| 合规支持 | 等保、数据安全、日志审计、私有化 |

## 公开资料对比模板

| 维度 | 微步在线 | 深信服 | 长亭科技 | 奇安信 |
|---|---|---|---|---|
| 公开定位 | 威胁情报与智能体安全 | 企业安全与云基础设施 | 应用与 Web 安全 | 综合网络安全 |
| 威胁情报 | 重点能力 | 有相关能力 | 部分场景 | 有相关能力 |
| NDR/流量检测 | 重点方向 | 有相关能力 | 部分方向 | 有相关能力 |
| EDR | OneEDR | 有终端产品 | 非主要定位 | 有终端产品 |
| SaaS/MDR | 重点方向 | 有服务能力 | 有安全服务 | 有服务能力 |

填表要求：

- 每个结论附公开来源；
- 不写“绝对领先”“完全替代”等结论；
- 不把厂商宣传指标直接当作客户实测结果；
- 对比目的是帮助客户选型，而不是贬低竞品。

## 售前表达

> 竞品对比的核心不是证明别人不行，而是证明在当前客户场景下，哪套能力组合、交付方式和成本结构最匹配。
