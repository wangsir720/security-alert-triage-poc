# 投标与实施方案交付包

## 1. 投标材料结构

### 商务部分

- 公司资质与项目经验；
- 商务条款和报价；
- 服务承诺与交付周期。

### 技术部分

- 需求理解；
- 总体方案；
- 产品架构与部署架构；
- 功能与性能响应；
- 安全合规；
- 实施计划；
- 培训和售后保障。

### 技术偏离应答表

| 招标要求 | 响应情况 | 偏离说明 | 证明材料 | 页码 |
|---|---|---|---|---|
| 支持 IOC 查询 | 完全响应 | 无偏离 | 产品手册/截图 | - |
| 支持 NDR 告警关联 | 完全响应 | 无偏离 | POC 报告 | - |

## 2. 实施方案

1. 项目启动与范围确认；
2. 资产和日志源梳理；
3. 平台部署与网络连通；
4. 告警采集、解析和资产关联；
5. 威胁情报接入；
6. 策略调优和误报优化；
7. 用户培训；
8. 试运行、验收和交接。

## 3. 讲标 PPT 骨架

1. 客户业务与安全挑战；
2. 当前问题和风险影响；
3. 方案总体架构；
4. 核心能力与场景演示；
5. POC 验证方法；
6. 实施计划和交付保障；
7. 案例与价值总结；
8. 下一步行动。

## 4. 与 POC 的衔接

投标材料中的承诺必须能在 POC 中被验证。POC 至少记录：

- 数据源和测试范围；
- 测试用例；
- 通过标准；
- 失败项和补救措施；
- 客户确认记录。
