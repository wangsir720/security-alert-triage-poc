# 常见异议 FAQ

## 1. 这是不是一个真实 SIEM？

不是。这是一个售前 POC，用脱敏样例数据验证告警分诊、情报富化和报告输出流程。目标是快速展示业务价值和交付路径，不替代生产级 SIEM。

## 2. 为什么先做本地情报库？

为了保证演示可复现，并避免 POC 依赖第三方 API 配额和网络状态。后续可以替换为 OTX、AbuseIPDB、GreyNoise 或企业现有情报平台。

## 3. 风险评分是否可靠？

当前是透明、可解释的规则评分，适合 POC 阶段。生产环境应根据客户资产、历史告警和业务影响重新校准权重。

## 4. 如何证明告警降噪效果？

至少需要记录：

- 告警总数；
- 高中低风险分布；
- IOC 命中率；
- 人工复核后的真实高危比例；
- 人工处理耗时和系统生成报告耗时。

不能只写“提升多少倍”，必须保留原始数据和对照口径。

## 5. 和微步产品方向有什么关系？

它对应威胁情报、告警运营、NDR/EDR 上下文富化和 Agent 化研判的通用业务问题。该 POC 不使用或冒充微步产品，而是展示对安全运营场景和 POC 交付方法的理解。
